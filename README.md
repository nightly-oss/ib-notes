# IB Wiki
This is the public repository for the **IB Wiki**, an open-source project by me ([Nightly](https://github.com/nightly-oss)). This repository contains the Markdown notes **AND** the Obsidian vault and its configuration to view or edit the notes locally. If you wan to:
- Contribute to the notes
- Download the notes so you can view them locally
- Copy my Obsidian config for the notes and have them locally-available in Obsidian

Then you’re in the right place. Cloning this repo will give you the Obsidian Vault filled with notes. Each note is an `.md` file and can be opened with practically any app out there, but I recommend using Obsidian as I have set it up already for you. Just download Obsidian (available for any device) and open this folder as a vault, choosing to “Trust the authors” to enable all the plugins and tools you might need. This setup takes just a minute to finish.

If you want to contribute, see [[CONTRIBUTING]].

If you want to view the code for this wiki (the Quartz config), do so [here](https://github.com/nightly-oss/ib-wiki).
